# portfolioHUB

Portfólio digital pessoal desenvolvido em **HTML5** e **CSS3**, com publicação via GitHub Pages.

## 🎯 Objetivo

Servir como vitrine pessoal e ponto de partida para o portfólio profissional, apresentando informações sobre formação, habilidades e contato.

## 🛠️ Tecnologias

- HTML5 (semântica)
- CSS3 (Flexbox, gradientes, responsividade)
- Git / GitHub
- GitHub Pages

## 📁 Estrutura

```
portfoliohub/
├── index.html   # Página principal
├── style.css    # Folha de estilos
└── README.md    # Documentação (este arquivo)
```

## ▶️ Como executar localmente

```bash
git clone https://github.com/ArthurFelipeQueiroz/portifolioHUB.git
cd portifolioHUB/projetos/portfoliohub
# Abrir index.html no navegador
```
